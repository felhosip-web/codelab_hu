## Leírás
Algoritmus vizualizáló - 36 plugin, dinamikus paraméterek, breakpointok, API 2.0, REST API biztonságos, FIFO/LIFO, tömbök, pointerek

## Pluginok (36)
- Rendezés (5): Bubble, Insertion, Quick, Merge, Heap
- Keresés (2): Linear, Binary
- Gráf (4): BFS, DFS, Dijkstra, A*
- Fa (6): BST, AVL, B-Tree, Trie, Traversal, Heap Tree
- Hash (1): Hash table
- Szöveg (3): KMP, Rabin-Karp, Boyer-Moore
- Kódolás (5): Huffman, RLE, Caesar, Base64, Enigma
- Hibajavító (2): CRC, Reed-Solomon
- Tömbök (4): Alapok, 2D, Pointerek, Tömbben tömb
- FIFO/LIFO (4): Verem LIFO, Sor FIFO, Körkörös sor, Deque

## Funkciók
- Dinamikus paraméterek: méret, max érték, szöveg stb.
- Lejátszás vezérlő: AUTO sebesség állítható + MANUAL előre/hátra + progress csúszka
- Breakpointok: előre definiált, feltételes (i==5), hit count (hit%10==0), logpoint
- Menük: Fájl, Szerkesztés, Nézet, Futtatás, Súgó - szellős felület
- Állapotmentés: mentés, visszatöltés, undo/redo, session export/import
- Billentyű hozzárendelés: beállításokban
- API 2.0: feature flag, finomhangolás, kompatibilitási réteg, hookok
- REST API: biztonságos, API kulcs, rate limit, IP whitelist, sandbox, audit log
- Licenc: GNU GPL v3 + HES Projects® Terms
- Teljesítmény mérés, auto-save, 6 nyelv kód nézet
